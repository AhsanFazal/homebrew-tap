# homebrew-tap

Public Homebrew tap.

```sh
brew tap ahsanfazal/tap
brew install --cask voiceink
```

Casks install personally-built, signed binaries published as GitHub releases
on this repo (tag scheme: `<app>-v<version>`). Sparkle appcasts live under
`appcast/`. Built from unmodified upstream release tarballs plus the small
patch scripts attached to each release (GPL source offer).

VoiceInk upstream: https://github.com/Beingpax/VoiceInk (GPL-3.0).
